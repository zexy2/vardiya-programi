# Screenshots

This folder contains screenshots used in the README documentation.

## Required Screenshots

| File | Description | Size |
|------|-------------|------|
| `demo.png` | Main app screenshot | 1080×1920 (or similar mobile aspect ratio) |

## Taking Screenshots

1. Open the app in Chrome DevTools
2. Enable device toolbar (Ctrl+Shift+M / Cmd+Shift+M)
3. Select a mobile device (e.g., iPhone 12 Pro)
4. Take screenshot using DevTools > More options > Capture screenshot

## Recommended Content

For the best demo screenshot, show:
- A few employees with recorded shifts
- Some overtime entries (green highlight)
- At least one day off (red/faded)
- The summary section with non-zero values
